# Conversation Widgets

This folder contains reusable conversation widgets rendered inside or around the chat experience.

Conversation widgets are interactive or structured UI blocks that are not part of the base chat shell.

Initial widget targets:

- booking-progress
- booking-summary
- slot-list

Each widget folder can also expose a direct `demo.html` page that imports the real widget assets for isolated visual editing.

Future widgets can be added here when they represent a self-contained conversation UI unit.
